## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->

- ATS output rules: single column; no tables, columns, text boxes, images, icons, headers or footers; real selectable text; standard fonts; normal bullet characters; no hidden keyword blocks or white text. (General)
- Standard section headings: Professional Summary, Core Competencies, Professional Experience, Education, Certifications, Skills, Languages. (General)
- PDF auto-fits to two pages by shrinking font size and spacing in small steps. (General)
- DOCX uses Calibri; PDF uses Arial on macOS and DejaVu on Linux, with an Arial Unicode fallback for non-Latin text. (General)
- Generated files are named `<Name>_<Company>_<Title>_<YYYYMMDD-HHMMSS>.pdf` / `.docx`. (General)
- An optional TTF font path (`CAREER_FIRM_FONT_PATH`) overrides the PDF rendering fonts. (General)

## Gotchas
<!-- Traps, false-failure causes, timing quirks. Tagged. -->

- Page fitting is approximate: DOCX reuses the same scale as the PDF, but Word's layout differs, so a two-page fit is not guaranteed in DOCX. (General)
- Complex RTL shaping in PDF may require `uharfbuzz` plus a font with adequate coverage. (General)
