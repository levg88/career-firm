## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->

- Agent definitions are data, not code: identity, system prompt, task template, output schema name, workflow label, temperature, and max tokens live in `agents/*.md`; the TypeScript classes under `src/agents/` are thin domain wrappers over those definitions. (General)
- The loader `src/agents/definitions.ts` searches the bundled `agents/` directory first, then `<home>/agents` (default `data/agents`, override with the `CAREER_FIRM_AGENTS_DIR` environment variable); when two files share an `id`, the later one replaces the earlier one, so user definitions override bundled ones. (General)
- Definition format is YAML-style frontmatter followed by a `# System Prompt` section and a `# Task` section; `# Task` supports `{{placeholder}}` variables, and object values are pretty-printed as JSON when substituted. (General)
- The frontmatter `schema:` field maps to a Zod schema in `src/agents/schema.ts`; valid values are `parsed_cv`, `job_analysis`, `tailored_cv`, and `none`. (General)
- `career-firm agents` lists the loaded definitions, and `career-firm agents --prompt <id>` prints a given agent's system prompt. (General)
- `src/agents/prompts.ts` has been removed; the three system prompts were moved verbatim into `agents/office-manager.md`, `agents/headhunter.md`, and `agents/resume-writer.md` (verified by exact text comparison). (General)

## Gotchas
<!-- Traps, false-failure causes, timing quirks. Tagged. -->

- Section splitting is level-1 only: only `# System Prompt` and `# Task` headings delimit sections, so subsections inside a task template must use `###` or deeper — a level-1 heading inside `# Task` silently starts a new (wrong) section. (General)
- Agent prompts are no longer in TypeScript: searching or patching `src/agents/prompts.ts` fails because the file was deleted; prompt edits belong in `agents/*.md`. (General)

## Pointers
<!-- Evidence files, specs, config locations. Links, never copies of config values. -->

- `agents/*.md` — bundled agent definitions (frontmatter + `# System Prompt` / `# Task`). (General)
- `src/agents/definitions.ts` — definition loader, search order, override rules, `CAREER_FIRM_AGENTS_DIR` handling. (General)
- `src/agents/schema.ts` — Zod schemas keyed by the frontmatter `schema:` value. (General)
- `<home>/agents` (default `data/agents`) — user-supplied definition directory that overrides bundled files by `id`. (General)
