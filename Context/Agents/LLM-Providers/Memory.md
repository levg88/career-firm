## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->

- Supported provider families: OpenAI / OpenAI-compatible, Anthropic, Ollama, OpenCode, and an Offline deterministic mode. (General)
- One OpenAI-compatible adapter covers OpenAI, Ollama, OpenRouter, vLLM, proxies and similar servers — any compatible endpoint is reachable through the base-URL setting. (General)
- Anthropic is called through its native Messages API with tool use, not an OpenAI-compatible shim. (anthropic / any OS, 2026-11-08)
- Ollama is reached through the same OpenAI-compatible adapter as OpenAI and needs no API key. (ollama / any OS, 2026-11-08)
- OpenCode is an OpenAI-compatible endpoint at `https://opencode.ai/inference/openai/v1`, authenticated with an OpenCode Console API key; it serves paid models plus the free chat models listed on OpenCode Console. (opencode / any OS, 2026-11-08)
- Offline mode is fully local and deterministic: it still parses CVs, scores jobs, renders PDF/DOCX and persists everything — only language quality degrades versus a real model. (General)
- Adding a provider means implementing `LLMClient.complete(...)` under `src/llm/`, normalizing tool calls to the `ToolCall` shape, and registering it in `buildLlm`. (General)
