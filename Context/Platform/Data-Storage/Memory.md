## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->

- Local data layout: `data/firm.db`; `data/storage/context/`; `data/storage/cvs/profile_<id>/`; `data/storage/jobs/profile_<id>/`; `data/storage/generated/job_<id>/`; `data/runs/tailor_<id>/` for run workspaces. (General)
- SQLite runs in WAL mode with one connection per operation. (General)
- The database file is created with mode `0600`. (General)
- Audit trail: `agent_runs` records role, provider, model, token usage and input/output for every agent call; `workflow_runs` records each tailor run's status, workspace and error. (General)
- Table purposes: `profiles` (context text + source filename), `cv_versions` (vertical, path, raw text, structured parse), `jobs` (JD, title, company, language, status, error), `analyses` (Headhunter JSON, score, selected CV), `generated_cvs` (tailored JSON, PDF/DOCX paths, warnings), `app_settings` (provider/model/URLs/keys/defaults). (General)
- Data stays on the machine except for prompt text sent to the configured model provider. (General)
- The entire data directory is relocatable with `--home DIR` or the home-directory environment override (default `./data`). (General)
