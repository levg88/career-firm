## Facts
<!-- Stable, verified knowledge. One bullet per fact. Tagged. -->

- Quickstart: `npm install` → `npm run build` → `npm start`; `npm run dev` adds auto-reload. (General)
- The app serves at `http://127.0.0.1:8765` by default; host and port are configurable. (General)
- CLI entry points: during development `npm run cli -- <command>` (runs through `tsx`); after a build `node dist/cli.js <command>`; a global install exposes `career-firm <command>`. (General)
- Command surface: `init`, `config`, `doctor`, `profile show|set-context|add-cv|list-cvs`, `job add|run|list|show`, `serve`, `agents`. (General)
- `--home DIR` overrides the data directory for any command. (General)
- `job add` accepts `--file`, `--title`, `--company`, `--language` and `--no-run` (ingest without tailoring); `job run ID` re-runs tailoring for an existing job; `job show ID --json` emits machine-readable job detail. (General)
- `doctor` checks the configured provider, dependencies, fonts and DB stats. (General)
- `config` prints the effective configuration with no secrets. (General)
- `serve` accepts `--host` and `--port` overrides. (General)
- Runtime requirements are Node.js 20+ only — no Python, LibreOffice or Pandoc needed. (General)
